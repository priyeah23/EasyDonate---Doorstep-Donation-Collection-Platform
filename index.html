ABOUT EASydonate

A small step toward a kinder world.

EasyDonate is a simple donation platform designed to make giving convenient for everyone. Instead of traveling to a donation center, donors can request a doorstep pickup.

The platform connects donors, NGOs, and volunteer collection teams while helping keep donation progress transparent and organized.

Frequently Asked Questions

Quick answers for donors, NGOs and volunteers.

Is the collection team paid?

No. EasyDonate can use a volunteer-based collection team. Volunteers support the community without receiving a pickup fee.

What items can I donate?

Useful items such as clothes, books, furniture, electronics and other accepted materials can be listed through the donation form.

How does tracking work?

Flask processes donation requests and MySQL stores submitted donation details.

How can NGOs participate?

NGOs can register, list current needs, receive matched donations and update delivery information.

Technical Details

EasyDonate uses a responsive frontend with a Flask backend and MySQL database.

💻

Frontend

HTML5, CSS3 and JavaScript for responsive user interfaces.

🐍

Backend

Python Flask handles routes, authentication, form submissions and application requests.

🗄️

Database

MySQL stores registered users, donation requests and contact messages.

User / Frontend→Flask Backend→MySQL Database→Response
☕

Application Layer

Java can support the application logic, with Spring Boot providing the framework for building scalable web services.

🔗

Service Communication

REST API can connect the user interface with application services for donation forms, pickup requests, tracking and NGO updates.

📄

Data Exchange

JSON can be used to exchange structured donation, user, pickup and status data between the web interface and services.

⚙️

Decision Engine

Java / rule-based logic can handle donation matching, priority rules, pickup assignment and status-based decisions.

🧪

Quality Checks

JUnit can test application logic, while manual / functional testing can verify forms, tracking and user flows.

🔀

Code Collaboration

Git can manage code versions and changes, while GitHub can host the project repository and support team collaboration.

🧩

Visual Design Layer

SVG can be used for lightweight icons, diagrams, workflow visuals and scalable project illustrations.

📱

Responsive Experience

The interface is designed to adapt across desktop, tablet and mobile screens, keeping donation and tracking features easy to use.

🔒

Reliable Data Flow

User requests move through the application layer to stored data and return as clear responses, supporting organized and traceable donation operations.

📋

Development Workflow

Agile / Scrum can be used to plan features in small iterations, review progress and continuously improve EasyDonate.
